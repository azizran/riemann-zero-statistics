## 2. TÜRETİM — `⟨σX̃^k⟩`'nin üçlü-toplamı (AÇIK)

### 2a. Merdivenden çizgi genliklerine: yarım-gap çarpanları

Sentetik gaz `N_sm(z) + S(z) = n`, `S(t) = −Σ_q a_q sin(ω_q t)`,
`ω_q = log q`, `a_q = 1/(πm√q)·(pencere)`. `N_sm' = 1/ḡ`, `ḡ = 2π/L`
olduğundan hiçbir yaklaşım yapmadan

```
ds_n = −[S(z_{n+1}) − S(z_n)] = Σ_q 2a_q sin(ω_q g_n/2)·cos(ω_q m_n)
```

`sin(ω_q g_n/2) → sin(πτ_q)` ile:

| alan | çizgi genliği | faz (site m_n) |
|---|---|---|
| `ds`, `η` | **b_q = 2a_q sin(πτ_q)** | 0 |
| `X̃ = dsΔ` (bond ort.) | **B_q = b_q cos(πτ_q) = a_q sin(2πτ_q)** | **+πτ_q** |
| `Ĉ = Σ dsΔ` | **a_q cos(πτ_q)** | −π/2 |

Birincisi kodun `gp = (2a_q sin(πw/L))²` sabitidir; üçüncüsü **162 §2b'nin
ölçtüğü `cos²(πτ)` sütunudur** (0.9550 ↔ cos²(π·0.075) = 0.9455). Yani
kinematik çarpanlar ayrı bir varsayım değil, **zaten ölçülmüş** nesnelerdir.

### 2b. Ölçüm nesnesinin tam ayrışımı

Tanım (160 §2, özdeş): `c_n = η_n e^{−iω_Q m_n}`, `⟨c⟩ = h_Q/2`
(`h_Q = zc`, ÖLÇÜLEN kompleks çizgi genliği), `ρ_n + iσ_n = c_{n+1}conj⟨c⟩`,
`⟨ρ⟩ = |h_Q|²/4`. Buradan

```
s_k = ⟨σX̃0^k⟩/⟨ρ⟩ = 2·Im[h̄_Q J_k]/|h_Q|² ,   J_k ≡ ⟨c_{n+1} X̃0_n^k⟩
u_k = ⟨ρX̃0^k⟩/⟨ρ⟩ = 2·Re[h̄_Q J_k]/|h_Q|²     (u_1 = S = 159/160'ın A·S'i)
```

η'yı **kendi çizgisi + gerisi** diye ayır (site `m_{n+1}`):

```
c_{n+1} = h_Q/2  +  (h̄_Q/2)e^{−2iω_Q m_{n+1}}  +  η^r_{n+1}e^{−iω_Q m_{n+1}}
           (T_a)          (T_b)                        (T_c)
```

* **(T_a) KENDİ ÇİZGİSİ.** `T_a = (h_Q/2)·⟨X̃0^k⟩`. `⟨X̃0^k⟩` REELDİR,
  dolayısıyla `Im[h̄_Q T_a] = Im[|h_Q|²⟨X̃0^k⟩/2] = 0` **ÖZDEŞ OLARAK**.
  Aynı terim `u_k`'ya `⟨X̃0^k⟩` verir ve `u_0 = 1`'i özdeş kılar.
  > **Bu, köşegen (Gauss) payın neden ölü olduğunun kalem ispatıdır:
  > çizginin kendi gücüyle X̃'nin varyansı arasındaki bağlaşım
  > `⟨ρ⟩`'ya gider, `⟨σ⟩`'ya DEĞİL** — ölçülen karşılığı `s0 ≤ 6.4e−04`
  > (V3) ve 160 §5a'nın `⟨σ⟩/⟨ρ⟩ ≤ 8e−05` kaydı.
* **(T_b) 2ω_Q harmoniği.** Yalnız `(q₂,q₃) = (Q,Q)` çifti besler;
  mertebesi `x_Q²` (ölçüldü: `\|s2_Tb\| ≤ 1e−05`, ihmal edilebilir).
* **(T_c) GERİSİ — üçlü-toplamın yaşadığı yer.**

### 2c. T_c: rezonans koşulu ve TEKLİK

`m_{n+1} − m_n = ḡ(1+X̃_n)` ÖZDEŞ olduğundan her `q₁ ≠ Q` terimi

```
⟨ e^{iν m_n} · e^{iA_ν(1+X̃_n)} X̃0_n^k ⟩ ,   ν = ω₁−ω_Q  (fark kanadı)
                                             ν = −(ω₁+ω_Q) (toplam kanadı)
```

biçimindedir (`A_ν = νḡ = 2πν/L`). Tarak-ortalaması `X̃0^k e^{iA_νX̃}`'nin
`−ν` bileşenini ister. `X̃ = Σ_q Re[x_q e^{iω_q m_n}]` olduğundan bu bileşen
ancak **iki X̃ çizgisi** birlikte üretebilir:

```
−ν = ε₂ω₂ + ε₃ω₃   ⟺   q₁ = Q · q₂^{ε₂} q₃^{ε₃}      (ÇARPIMSAL ÜÇLÜ)
```

**TEKLİK.** `Q = p^a`, `q₁ = r^b`, `r ≠ p` olsun. `q₂ = s^c`, `q₃ = t^d`
asal kuvvetleridir; tek çarpanlara ayırma `r^b·p^{-a} = s^{ε₂c}t^{ε₃d}`
denklemini **yalnız** `{s,t} = {r,p}` ile çözer, yani
**(q₂,q₃) = (Q, q₁)** (ve sıralı eşi). Aynı asalın kuleleri
(`r = p`) ek çözüm verir; `kule_ciftleri` bunları sayar, bant
çizgilerinin çok küçük bir kesridir.

Bileşenin katsayısı X̃'nin **ikinci türevidir** (köşegen "dressing"
otomatik olarak içindedir, tam X̃ ile ölçülür):

```
Γ(θ,k) ≡ ⟨ d²/dX² [ e^{iθ(1+X)} X0^k ] ⟩
       = e^{iθ}[ k(k−1)Φ_{k−2}(θ) + 2ikθ Φ_{k−1}(θ) − θ² Φ_k(θ) ]
Φ_j(θ) ≡ ⟨ X̃0^j e^{iθ X̃} ⟩        (X̃'nin MARJİNALİ; histogram+ızgara,
                                     Φ_j(0) − ⟨X̃0^j⟩ ≤ 1.0e−14, V2)
```

### 2d. KAPALI FORM

```
J_k = (h_Q/2)·Φ_k(0)                                            (T_a)
    + (h̄_Q x_Q²/8)·Γ(−4πτ_Q, k)                                 (T_b)
    + (x_Q/8)·Σ_{q₁≠Q}[ h₁x̄₁·Γ(2π(τ₁−τ_Q),k)                    (T_c, fark)
                       + h̄₁x₁·Γ(−2π(τ₁+τ_Q),k) ]                (T_c, toplam)
```

### 2e. ÇIPLAK LİMİT ve İŞARET MUHASEBESİ

`Φ_0→1, Φ_1→0, θ²σ²`'yi ihmal ve `h_q = b_q`, `x_q = B_q e^{iπτ_q}` koy:
`Γ(θ,2) → 2e^{iθ}` ve iki kanat birleşir
(`sin(X+Y) − sin(X−Y) = 2cos X sin Y`):

```
   s2  =  −cos(πτ_Q)·sin(πτ_Q) · Σ_{q₁} b₁B₁cos(πτ₁)
       =  −½ sin(2πτ_Q) · Σ_{q₁} a₁² sin²(2πτ₁)
       =  −sin(2πτ_Q) · Var_merdiven(X̃)|_{τ>taban}
```

**İşaret muhasebesi (T4'ün analitik yanıtı) tam olarak şudur:**

| çarpan | kaynak | işareti |
|---|---|---|
| `−sin(πτ_Q)` | taşıyıcının kuadratürü `Im[e^{−iπτ_Q}]` | τ_Q ∈ (0,1)'de **daima −** |
| `cos(πτ_Q)` | X̃'nin bond-ortalama kazancı (`x_Q/b_Q`) | τ_Q < ½ → +, τ_Q > ½ → **−** |
| `Σ b₁B₁cos(πτ₁) = Σ4a₁²sin²(πτ₁)cos²(πτ₁)` | merdiven toplamı | **daima ≥ 0** |

Yani **işareti tek başına `cos(πτ_Q)` çevirir** ve sıfır geçişi
`τ_Q = ½`'tedir — 158/160'ın `τ₀ ≈ 0.5` kinematik kökünün üçüncü-moment
karşılığı. **Gaza bağlı tek nicelik pozitif bir skalerdir**; bu yüzden
birinci mertebede **hiçbir gaz farkı işaret çeviremez** (§6a).

   `s2 = Σ_{a,b}|x_a||x_b|·Re[e^{iπν_{ab}/L}Ŝ(ν_{ab})]` ve X̃ tarafı
   (genlikler + `πτ` fazları) TAM biliniyor. Geriye kalan tek bilinmeyen
   `Ŝ`'dir; ölçülmesi ucuzdur (bir O(N) geçiş / frekans) ve gerçek ↔ A4
   işaret farkı **doğrudan `Ŝ`'de aranmalıdır**.
2. **Tarak çekirdeği `κ(Δ) = ⟨e^{iΔ m_n}⟩` doğrudan ölçülmeli** ve
   `Ψ` ile konvole edilmelidir. `νḡσ_Ĉ ≈ 0.84 rad` olduğundan 143'ün
   birinci-mertebe `𝒢`'si yetmiyor; `κ`'nın kendisi ölçülebilir ve
   `e^{iνḡĈ}`'nin tam karakteristik fonksiyonudur — 160'ın `E1`'iyle
   aynı ailedendir.
3. **152'nin Newton'u merdiveni eksik kuruyor** (keskin %54, A4 %85).
   Bu, 152/154/155'in bütün sentetik gazlarını etkileyen bir kayıttır ve
   162 §2d'nin yan bulgusunu doğruluyor. Daha çok iterasyon / daha az
   sönümle yeniden koşulan bir "keskin-v2" gazı, sentetik laboratuvarın
   niteliğini doğrudan artırır.
4. **`u_1 = S` bile öngörüde ×5–×20 küçük.** Yani eksik katman üçüncü
   momente özgü değil; `A·S`'nin kendisi de tarak-aracılıdır. Bu, 159/160'ın
   "kesme çarpanı"nı yeniden okumak için bir kapı.
5. **`orta`, `P1`, `dusuk` bu koşuda ölçülmedi;** taban ekseni yalnız 0.40,
   ızgara yalnız `t1`.
